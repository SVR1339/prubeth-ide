1. Executive Summary & Product Scope

Independent AI-Native Desktop IDE vs. Chatbots

PRUBETH IDE is an autonomous desktop environment. It executes directly in your local repositories, eliminating the need to copy-paste code to cloud chat boxes.

  • No External Codex / Cloud Chat Locks: Operates natively with local Ollama/GGUF models or direct cloud APIs.
  • In-Place Execution: Directly modifies files, runs terminal commands, executes tests, and performs multi-file rollbacks.
  • Multi-Agent Team: Architect (DAG Planner) → Senior Coder → Security Critic (AST Guard) → QA Tester (Pytest Automation).
